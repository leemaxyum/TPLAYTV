# Branding Ideation Brief

## Task

Ideate an original name, positioning, and visual direction for this product. Do not imitate Apple, PlayStation, Wii, Xbox, Discord, or any existing product’s trade dress.

## Product

A premium, local-first shared space for student groups.

One host uses a TV/laptop to run a room. Participants join with phones on the same Wi-Fi. The product supports:

- party games
- quizzes and course knowledge boosters
- classes and meetings
- events
- study rooms, tasks, notes, and softboards
- multi-host rooms and multiple simultaneous participant environments

A participant’s phone is an actual personal app: identity, current environment, score, status, and context-specific actions—not only a remote control.

## Product feeling

Calm, intentional, tactile, warm, modern, and premium. “Premium” means clarity, useful hierarchy, excellent empty states, and real feedback—not glossy imitation.

## Naming criteria

The name should:

1. Work for games, learning, classes, and events—not only gaming.
2. Feel social and spatial: a place people enter together.
3. Be short, pronounceable, and easy to spell.
4. Avoid generic tech words where possible: hub, sync, meta, smart, play, AI, game.
5. Avoid obvious similarity to major existing products.
6. Have room for a simple icon and a clean wordmark.
7. Avoid using “Stellar” or “Stellar Play.”

## Deliverable format

Provide:

- 20 name candidates, grouped by tone
- Top 5 with rationale, possible taglines, and risks
- One recommended name
- Brand personality: 5 adjectives and 5 “not us” adjectives
- Colour/material/motion direction in plain language
- Examples of UI microcopy for: create room, join room, waiting, activity start, host announcement
- A short trademark/domain research checklist (do not claim a name is legally available without checking)

## Existing working thought

“Commonroom” is a strong early candidate because it fits gathering, study, events, and play. Treat it as a candidate, not a decision.
